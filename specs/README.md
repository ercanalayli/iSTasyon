# AperiON specifications

GitHub is the code source of truth. This directory is the product-requirements
source of truth. Operational truth lives in AperiON's canonical stores with source
health and evidence.

Material work follows: constitution -> spec -> clarify -> plan -> tasks ->
implementation -> verification -> read-back.

Initial capability map:

- APERION-001: Personal AI memory and context engine
- APERION-002: Universal inbox (WhatsApp, Telegram, Gmail, documents)
- APERION-003: Approval and guardian engine
- APERION-004: BizimHesap accounting agent
- APERION-005: Morning brief and commitment timeline
- APERION-006: Connector health and reconciliation
- APERION-007: Personal, family, home, health, and learning domains
- APERION-008: Decision challenge and outcomes
- APERION-009: Notification and remote mobile control
- APERION-010: Agent interoperability, only after measured need

Only APERION-001 is activated by this change. The rest are roadmap identifiers,
not claims of completed functionality.
